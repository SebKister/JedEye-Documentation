# Setting the Unit System

You can select either the metric system ( using meter and ºC) or the imperial system ( using feet and ºF) to be displayed on the JedEye.
In the menu navigate to :

**OPTIONS > SETTINGS > DEVICE > UNIT** to select the active unit system. The entry shows the active one,
**UNIT (m)** or **UNIT (ft)**, and selecting it switches to the other one.

> The unit system used on the device can be different from the one used in your mapping software
